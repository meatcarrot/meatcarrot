정합성과 복구 가능성을 고려한 시스템을 설계하고 구현하는 **Java/Spring 기반 백엔드 개발자**입니다.

저는 AI 서비스, 데이터 처리, 금융성 시스템 프로젝트를 경험하며  
**“실제 운영 환경에서 버틸 수 있는 구조”**를 만드는 데 관심을 가져왔습니다.

## Key Experience

### 1. 금융 송금 시스템 설계
- 송금 과정에서 발생할 수 있는 **DB 반영과 메시지 발행 불일치 문제**를 고민하며 구조를 설계했습니다.
- Kafka 기반 비동기 처리, Ledger 기록, Outbox 관점을 바탕으로  
  **중복 처리, 장애 상황, 재처리 가능성**까지 고려했습니다.

### 2. 인천국제공항 AI 챗봇 고도화
- DB, 백엔드, 배포를 맡아 실제 서비스 운영 흐름을 경험했습니다.
- 질문 의도 분류 구조에 따라 핸들러를 나누고, API 연동 및 서버 구성을 담당했습니다.
- 응답 구조와 검색 흐름을 개선하며 **성능과 안정성**을 함께 고민했습니다.

### 3. AI 서비스와 백엔드의 연결
- 단순히 모델 성능만 보는 것이 아니라,  
  **데이터 저장 구조 / 검색 구조 / API 응답 흐름 / 배포 환경**까지 포함한 서비스 관점으로 프로젝트를 진행했습니다.
