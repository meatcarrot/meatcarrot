# 안녕하세요, 백엔드 개발자 이희연입니다 👋

정합성과 복구 가능성을 고려한 시스템을 설계하고 구현하는 **Java/Spring 기반 백엔드 개발자**입니다.  
단순한 기능 구현에 그치지 않고, **트랜잭션, 데이터 일관성, 장애 대응, 복구 가능성**을 함께 고려하는 시스템을 설계합니다

AI 응용 서비스, 데이터 처리, 금융성 시스템 프로젝트를 진행하며
**실제 운영 환경에서 버틸 수 있는 구조**에 관심을 가지고 나아가고 있습니다

## Key Experience

### 1. 금융 송금 시스템 설계
- 송금 과정에서 발생할 수 있는 **DB 상태와 메시지 발행 불일치 문제**를 고민하여 구조를 설계했습니다.
- Kafka 기반 비동기 처리, Ledger 기록, Outbox 관점을 바탕으로  
  **중복 처리, 장애 상황, 재처리 가능성**을 고려했습니다.
- 추가적으로 송금 외 다른 기능들을 업데이트 할 예정입니다
  
### 2. 인천국제공항 AI 챗봇 고도화
- DB, 데이터 파이프라인, 서버, 배포를 맡아 실제 서비스 운영 흐름을 경험했습니다.
- 질문 의도 분류 구조에 따른 개별적인 핸들러를 일부 구현하고, 실시간 데이터 연동 및 서버 구성을 담당했습니다.
- 벡터 유사도와 캐싱을 활용한 응답 구조을 개선하며 **성능과 안정성**을 함께 고민했습니다.

### 3. 공모전 기반 데이터 활용 및 문제 해결 경험
- 데이터 기반 공모전에 참여하며, 주어진 문제를 분석하고 이를 해결할 수 있는 방향으로 아이디어와 결과물을 구체화하는 과정을 경험했습니다.
- 데이터의 의미를 해석하고, 필요한 정보를 정리·가공해 실제로 활용 가능한 형태로 만드는 과정을 수행했습니다.
- 이 경험을 통해 단순히 기능을 구현하는 것을 넘어, **문제를 정의하고 설계하며 결과물로 연결하는 과정 전체**를 바라보는 시각을 키울 수 있었습니다.
